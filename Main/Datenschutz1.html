2. Welche Daten beim Besuch der Website anfallen können

Beim Aufruf dieser Website können technisch notwendige Verbindungsdaten verarbeitet werden, etwa IP-Adresse, Datum und Uhrzeit des Zugriffs, Browsertyp, Betriebssystem und angeforderte Datei. Solche Daten fallen typischerweise beim Hosting und der Auslieferung von Webseiten an.

Die Website selbst setzt keine eigenen Tracking-Cookies, keine eingebetteten Analyse-Skripte und keine eigenen Nutzerkonten auf Seitenebene ein.

Die Website ist für eine statische Bereitstellung ausgelegt. Bei einer Veröffentlichung über Plattformen wie GitHub Pages oder vergleichbare Hosting-Dienste können Zugriffsdaten durch den jeweiligen technischen Anbieter zur sicheren Auslieferung, Stabilität und Missbrauchserkennung verarbeitet werden.

4. Kontaktaufnahme über das Support-Formular

Wenn du das Support-Formular nutzt, werden die von dir eingegebenen Daten wie Name, E-Mail-Adresse, ausgewählte App und Nachricht verarbeitet, um dein Anliegen zu beantworten.

Für die technische Übermittlung des Formulars wird ein externer Formular-Dienst genutzt. Die Verarbeitung erfolgt nur insoweit, wie sie für den Empfang und die Bearbeitung deiner Nachricht erforderlich ist.
